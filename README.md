## 项目简介

本项目针对城市小户型家庭空间紧凑、设备分散、手动控制不便的问题，设计一套基于 **ESP32-S3** 的智能家居联动控制系统。系统集成多传感器数据采集、MQTT 云端通信和移动端远程控制，实现环境感知自动联动与安防预警，重点考察传感器应用与物联网终端联动开发能力。

### 核心目标

- 部署多传感器网络，实现环境数据实时采集
- 基于阈值规则与场景模式实现设备自动联动
- 通过 MQTT 协议上云，支持手机 APP 远程监控
- 实现离家模式、安防模式等场景化一键切换

## 功能需求

### 1. 智能照明控制

| 场景 | 触发条件 | 联动动作 |
|------|---------|---------|
| 人来灯亮 | PIR 检测到人体且环境光照不足 | 自动开启 LED 灯 |
| 人走灯灭 | PIR 持续未检测到人体 | 延时关闭 LED 灯 |
| 亮度自适应 | 光敏电阻采集光照强度 | 根据光照等级调节 LED 亮度 |

### 2. 智能温控

| 场景 | 触发条件 | 联动动作 |
|------|---------|---------|
| 高温通风 | 温度超过设定阈值 | 自动开启排风扇 |
| 湿度调节 | 湿度超过设定阈值 | 启动排风扇除湿 |
| 恒温保持 | 温度降至正常范围 | 自动关闭排风扇 |

### 3. 安防监控

| 场景 | 触发条件 | 联动动作 |
|------|---------|---------|
| 入侵检测 | 设防状态下门磁检测到门窗异常开启 | 蜂鸣器报警 + APP 推送告警 |
| 离家模式 | 用户通过 APP 一键启用 | 自动关灯、断电、启用安防 |
| 回家模式 | 用户通过 APP 一键启用 | 解除安防、恢复照明、温控就绪 |

### 4. 远程控制

- 手机 APP 实时查看各传感器数据
- 远程控制灯光、风扇、继电器开关
- 接收异常事件推送通知
- 场景模式一键切换

## 快速开始

### 环境准备

1. 安装 [VS Code](https://code.visualstudio.com/)
2. 安装 **PlatformIO** 扩展
3. 安装 ESP32-S3 USB 驱动（[CP210x](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers) 或 CH340）

### 编译与烧录

```bash
# 克隆仓库
git clone <repo-url>
cd smart-home-esp32

# PlatformIO 编译
pio run

# 烧录到开发板
pio run --target upload

# 查看串口日志
pio device monitor
```

### 配置 WiFi 与 MQTT

在 `src/config.h` 中修改以下配置：

```c
#define WIFI_SSID     "你的WiFi名称"
#define WIFI_PASSWORD "你的WiFi密码"

#define MQTT_BROKER   "你的EMQX服务器地址"
#define MQTT_PORT     1883
#define MQTT_CLIENT_ID "smart_home_001"
```

## 注意事项

1. **供电**：多传感器并行时建议使用 **5V/2A 独立电源**，避免 USB 供电不足导致传感器读数异常
2. **引脚规划**：ESP32-S3 GPIO 部分用于内部功能（如 PSRAM），接线前先确认引脚可用性
3. **MQTT 主题命名**：统一使用 `home/{room}/{device}/{action}` 格式，避免混乱
4. **WiFi 重连**：务必实现 WiFi 断线自动重连与 MQTT 重订阅机制
5. **安全**：演示阶段继电器控制强电需老师在场指导，正式演示建议全部使用 5V 低压模拟
