# 系统架构说明

## 总体架构

```
┌──────────────────────────────────┐
│         手机 APP                  │
│   (DevEco Studio / 鸿蒙开发)      │
└────────────┬─────────────────────┘
             │ MQTT (订阅/发布)
             ▼
┌──────────────────────────────────┐
│     华为云 EMQX (MQTT Broker)      │
│   数据中转 · 消息路由 · 设备管理    │
└────────────┬─────────────────────┘
             │ MQTT (WiFi)
             ▼
┌──────────────────────────────────┐
│         ESP32-S3 主控节点         │
│  ┌────────────────────────────┐  │
│  │   系统核心 (FreeRTOS)        │  │
│  ├────────────────────────────┤  │
│  │ 传感器采集 │ 联动引擎 │ 通信 │  │
│  └────────────────────────────┘  │
└──┬──────┬──────┬──────┬────┬─────┘
   ▼      ▼      ▼      ▼    ▼
 温湿度  光敏    PIR   门磁  执行器
```

## 数据流

1. **上行**：传感器 → ESP32-S3 → MQTT Publish → EMQX → APP 订阅
2. **下行**：APP 控制 → MQTT Publish → EMQX → ESP32-S3 订阅 → 执行器
3. **联动**：ESP32-S3 内部规则引擎检测条件 → 直接控制执行器 → 上报状态

## 模块设计

| 模块 | 职责 | 文件 |
|------|------|------|
| 传感器采集 | 读取传感器原始数据 | `sensors/*.h` |
| 执行器控制 | 控制 LED/蜂鸣器/继电器/舵机 | `actuators/*.h` |
| WiFi 管理 | WiFi 连接与自动重连 | `wifi_manager.h/.cpp` |
| MQTT 通信 | 消息收发与 Broker 对接 | `mqtt_client.h/.cpp` |
| 联动引擎 | 条件-动作规则匹配 | `logic/linkage_engine.h` |
| 场景管理 | 回家/离家/睡眠模式切换 | `logic/scene_manager.h` |
| 告警管理 | 入侵/火警检测与推送 | `logic/alarm.h` |
